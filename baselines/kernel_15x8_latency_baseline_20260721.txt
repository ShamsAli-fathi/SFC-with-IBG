Kernel 15-flow x 8-replica latency baseline
Recorded: 2026-07-21

Purpose
-------
This is a small comparison baseline for future Kernel-route runs.  It records
the two clean, same-configuration exploratory runs after the transient
high pair-RPC residual period.  It is not a replacement for the supported
3-flow/5-replica Kernel gate and does not change any SLA, utility, jitter, or
pair-cost semantics.

Interpretation
--------------
The pair-route value is the measured post-placement forwarder-to-forwarder
residual.  It is included in end-to-end latency and realized utility but never
in replica selection.  These two traces show a healthy observed 15x8 runtime
snapshot: all final flows met the 110-ms SLA.  Treat this as a comparison point,
not a performance guarantee; reproduce with the same configuration before
calling a future deviation a regression.
